# Mock Data Examples

Dữ liệu giả để OpenClaw/dev chạy end-to-end không cần provider thật.

## Files
- `market_snapshot.vn.json`: chỉ số, breadth, sector, foreign flow, phái sinh.
- `ohlcv_sample.vn.json`: mẫu OHLCV/factor kỹ thuật cho FPT, MWG, VCB, SSI.
- `portfolio_sample.json`: danh mục demo.
- `news_sample.vn.json`: tin đã chuẩn hóa + ticker tagging.
- `fundamentals_sample.vn.json`: financials + valuation + peer percentile.
- `macro_rates_sample.vn.json`: lãi suất, tỷ giá, global macro.
- `asset_ledger_sample.json`: tài sản cá nhân + liabilities + cashflow.

## Rule
Mock data chỉ để test luồng. Không dùng làm quyết định đầu tư thật.
